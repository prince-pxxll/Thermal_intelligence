# Architecture Decision Records (ADRs)

This directory records significant, hard-to-reverse decisions made during the project —
why a particular library, schema, or modeling approach was chosen over alternatives.

## Format

Each ADR is a new file named `NNNN-short-title.md` (e.g. `0001-use-st-dbscan-for-clustering.md`)
containing:

```markdown
# NNNN. Short title

## Status
Proposed | Accepted | Superseded by NNNN | Deprecated

## Context
What problem or decision point prompted this?

## Decision
What did we decide?

## Consequences
What becomes easier or harder as a result? What did we give up?
```

## Why bother

- New contributors can understand *why* the code looks the way it does, not just *what*
  it does.
- Revisiting a past decision starts from the recorded context instead of institutional
  memory.
- Decisions that get superseded stay visible instead of silently vanishing.
